Simulate execution plan without running any commands

Usage: enact dry-run [OPTIONS] [TARGET]

Arguments:
  [TARGET]  Target workflow, stage, component, or job to simulate (e.g. 'ci', 'local', 'core', 'core:test')

Options:
  -p, --pipeline <PIPELINE>
          Path to CUE pipeline file or .enact/ directory
  -w, --workflow <WORKFLOW>
          Specific workflow to simulate (e.g. 'local', 'ci'); without it, the default, else the first workflow running every `-c`/`-j` named
  -s, --stage <STAGE>
          Filter simulation by stage name
  -j, --job <JOB>
          Run only this job of every component (e.g. test, build, lint); refused beside a `component:job`
  -c, --component <COMPONENTS>
          Components to plan, comma-separated; `component:job` names that component's job
  -f, --files <FILES>
          Changed files (comma-separated or multiple flags). If empty, inspects git diff
  -u, --updated <UPDATED>
          Mark specific components as updated to simulate changes and resolve affected blast radius
  -a, --all
          Force inclusion of all components regardless of git changes
      --base <BASE>
          Git base ref to compare against; with `--files`, the commit they changed from, by which a bumped lockfile's installs are judged (CI's matrix commands pass detect's) [default: HEAD]
  -r, --resources
          Display detailed planned resource usage and sharding allocation
      --json
          Output planned simulation in structured JSON format
      --planning-inputs <PLANNING_INPUTS>
          JSON host and calibration inputs for reproducible planning
      --history <HISTORY>
          Plan from this history directory, as `enact affected --history`
      --snapshot
          Output compact decision-only JSON for snapshots (use fixed planning inputs for replay)
      --headroom-ram-pct <HEADROOM_RAM_PCT>
          Override headroom percentage of available RAM (e.g. 10.0 for 10%) [env: ENACT_HEADROOM_RAM_PCT=]
      --headroom-ram-mb <HEADROOM_RAM_MB>
          Override absolute RAM headroom in MB [env: ENACT_HEADROOM_RAM_MB=]
      --headroom-cpus <HEADROOM_CPUS>
          Override CPU headroom in vCPUs (e.g. 2.0) [env: ENACT_HEADROOM_CPUS=]
      --diff-base <DIFF_BASE>
          Compare the plan against a baseline revision or range (e.g. HEAD~1 or main..HEAD)
      --budget
          Exit 3 for unknown target-bearing job counts, or untraced tests/forecast wall time over `ci.budget` (the plan's `cost` explains the verdict)
  -h, --help
          Print help
